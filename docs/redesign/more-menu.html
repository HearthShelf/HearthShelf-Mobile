Before this gets built

Four of these eight are real screens today — Discover, Downloads, Settings and Server Settings. Every row is drawn enabled here; the disabled / empty states get spec'd separately.

  • Discover — built, at app/discover.tsx. Moving it here means dropping the sparkle button I put in the Home header.
  • Downloads — exists as app/settings/storage.tsx ("Downloads & storage"). Promoting it to a quick link is a second entry point, not a new screen.
  • Settings — today's More screen becomes a pushed route.
  • Server Settings — app/settings/admin.tsx, admin-only.
  • QuestGiver, History, Collections, Playlists — web-only today. Each needs a screen and an API client before its row does anything.

So the menu itself is small; the work is the four missing screens behind it.
